# ClearSky 双语翻译 · Chrome 应用商店上架指南

## 一、上架前你需要准备的

1. **开发者账号**：在 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole) 注册，一次性缴纳 5 美元注册费，并完成邮箱验证。
2. **隐私政策网址**：商店要求填写一个公开网址。把插件里的 `privacy.html` 放到你的网站上，比如 `https://tangzhihong.com/clearsky-translate/privacy`。**上传前把文件里"【请填写你的联系邮箱】"换成你愿意公开的邮箱。**
3. **上传包**：`clearsky-translate-1.0.0.zip`（已打包好，不含测试和设计文件）。

## 三、商店文案（可直接粘贴）

**名称**：ClearSky 双语翻译（英文区自动显示 ClearSky Bilingual Translate）

**简短说明**（已写在插件里，132 字符以内）：
网页双语对照/整页替换翻译，视频双语字幕。支持 DeepSeek、通义千问、OpenAI 等大模型，也可零配置使用免费翻译。

**详细说明**：

```
ClearSky 双语翻译：读外文网页、看外文视频，一个插件搞定。

【网页翻译】
• 双语对照：每段原文下方显示译文，适合阅读外文资料、研报、新闻
• 仅显示译文：整页替换成中文，链接照常可点
• 两种模式随时切换，切换不重复请求，速度快、省费用
• 只翻译你看到的部分，长页面不卡顿；网页后加载的内容也会自动翻译
• 自动跳过代码块、输入框和本来就是中文的段落
• 可设置"总是翻译此网站"，打开即译
• 5 种译文样式：简洁、柔和灰、虚线、荧光笔、引用竖线
• 快捷键 Alt+A、右键菜单、页面悬浮按钮，三种方式一键翻译

【视频双语字幕（YouTube）】
• 打开字幕后自动换成双语字幕：原文在上、译文在下
• 自动生成的字幕先按句断开再翻译，不再是一个词一个词地跳
• 优先翻译当前播放位置，拖动进度条也能马上跟上
• 字号、颜色、背景透明度可调，可只显示译文

【翻译引擎】
• 零配置：默认使用谷歌免费翻译
• 接入大模型：DeepSeek、通义千问（阿里云百炼）、Kimi、智谱 GLM、OpenAI、OpenRouter，或任何 OpenAI 兼容接口
• 智能模式：大模型出错时自动退回免费翻译，不会翻译到一半卡住

【隐私】
• 没有自己的服务器，不收集任何浏览数据
• 文字只发送给你选择的翻译服务
• API Key 只保存在本机浏览器，不同步、不上传
```

**类别**：生产工具（Productivity）或 工具（Tools）
**语言**：中文（简体），可另加 English

## 四、"隐私权"标签页怎么填

**单一用途说明**：
> 将网页内容和视频字幕翻译成用户选择的语言，并以双语对照或替换原文的方式显示。

**权限理由**：

| 权限 | 填写的理由 |
|---|---|
| storage | 保存用户的翻译设置（目标语言、显示方式、字幕样式、总是翻译的网站列表）和 API Key。 |
| contextMenus | 提供右键菜单"翻译此页面 / 恢复原文"和"切换双语/仅译文"。 |
| 主机权限（内容脚本 http/https 全部网站） | 用户可以在任意网站上翻译网页，插件需要读取页面段落文字并在原文旁插入译文。只有在用户点击翻译、或主动开启"总是翻译此网站"时才处理页面内容。 |
| 主机权限 translate.googleapis.com | 默认翻译引擎，用于获取译文。 |
| 可选主机权限 | 只在用户配置大模型接口时，申请访问用户填写的那个接口域名，用于调用翻译。 |
| 远程代码 | 选"否，我没有使用远程代码"。 |

**数据使用**（勾选项）：
- 勾选 **"网站内容"**（需要翻译的页面文字会发给翻译服务）
- 其他类别（个人身份信息、健康、财务、位置、浏览记录等）**都不勾**
- 三项声明全部勾选：不出售给第三方 / 不用于与核心功能无关的用途 / 不用于信用评估

## 五、提交步骤

1. 开发者控制台 → 新增内容 → 上传 `clearsky-translate-1.0.0.zip`
2. "商品详情"：粘贴文案，上传图标、截图、宣传图
3. "隐私权"：按第四节填写，粘贴隐私政策网址
4. "分发"：免费，地区选全部（或按需）
5. 提交审核。因为申请了"所有网站"的内容脚本权限，审核通常需要几天到两周

## 六、审核风险提示

- **谷歌免费接口**（translate.googleapis.com 的 gtx 接口）是非官方接口，市面上很多翻译插件在用，但存在被限流或日后失效的可能；智能模式下配置了大模型会优先走大模型。
- **商标**：插件名称和图标没有使用 YouTube、Google 的名称或标志；说明里出现"YouTube"只是描述支持的网站，属于常见写法。
- **截图**：截图里的视频画面是演示用的通用播放器，不含任何第三方标志。
