ClearSky 双语翻译 隐私政策

生效日期：2026 年 10 月 1 日 · 开发者：ClearSky

一句话说明

本插件没有自己的服务器，不收集、不存储、不出售、不分享你的个人信息或浏览记录。

插件会处理哪些数据

  • 待翻译的文字：当你主动翻译网页、或在视频中开启双语字幕时，插件会把页面上需要翻译的段落文字或字幕文字，发送给你选择的翻译服务（谷歌翻译，或你在设置中填写的大模型服务商，例如 DeepSeek、阿里云百炼、OpenAI 等），以获取译文。这些文字只用于翻译，插件开发者看不到。
  • 你的设置：目标语言、显示方式、字幕样式、"总是翻译"的网站列表，保存在浏览器的 chrome.storage.sync 中，会随你的 Chrome 账号在你自己的设备间同步。
  • API Key：只保存在当前浏览器的 chrome.storage.local 中，不会同步，只会在调用你所选服务商接口时作为身份凭证发送给该服务商。
  • 译文缓存：为节省费用和时间，近期译文临时保存在插件后台内存中，浏览器关闭或插件休眠后自动清除，也可在设置页一键清空。

第三方服务

翻译服务商对你发送的文字如何处理，适用该服务商自己的隐私政策（例如 Google 隐私权政策，或你所使用的大模型服务商的条款）。请勿在不信任的服务商处翻译敏感内容。

权限说明

  • activeTab 与 scripting：插件平时不读取任何网页。只有当你点击插件图标、按快捷键或使用右键菜单时，Chrome 才临时允许插件访问当前这一个标签页，用于识别段落并插入译文。
  • YouTube（www.youtube.com）：读取播放器已加载的字幕并显示双语字幕。
  • translate.googleapis.com：默认翻译引擎，用于获取译文。
  • 可选的网站访问权限：只在两种情况下、针对单个网站申请——你开启某个网站的"总是翻译此网站"，或你配置大模型接口时访问你填写的接口域名。可随时在设置中移除。
  • storage：保存你的设置。contextMenus：提供右键菜单"翻译此页面"。

数据的出售与使用限制

插件不会出售用户数据，不会将用户数据用于与翻译功能无关的用途，不会用于判断信用或发放贷款，也不包含任何广告或分析追踪代码。

Privacy Policy (English)

ClearSky Bilingual Translate has no server of its own and does not collect, store, sell or share personal data or browsing history.

When you translate a page or turn on bilingual subtitles, the text to be translated is sent only to the translation service you choose (Google Translate, or the LLM provider you configure) to obtain the translation. Settings are stored in chrome.storage.sync; your API key is stored only in chrome.storage.local on this device and is sent only to the provider you configured. Recent translations are cached in memory and discarded when the extension's background worker stops.

The extension does not read any page by default: it uses activeTab to access only the current tab when you click its icon, press its shortcut or use its context menu. Host access is limited to YouTube (for subtitles) and the translation endpoint; optional per-site permission is requested only for sites you choose to always translate and for the API endpoint you enter.
